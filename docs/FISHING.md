# Рыбалка AHelperW Fishing

Основной режим — **распознавание поклёвки по изображению поплавка**:
[FISHING_VISION.md](FISHING_VISION.md) (зона, запись, разметка, проверка, результаты).
Здесь — установка HUD, протокол, цикл нажатий, остановки и прежний режим «по отметке шкалы».

Цикл: заброс → ожидание → подсечка → подтверждение улова этого заброса → следующий заброс,
до заполнения сумок. Отдельная программа `AHelperWFishing.exe`; боевой помощник нужно закрыть
(общий mutex). HUD рыбалки не зависит от класса.

## Установка и обновление HUD

1. Установщик `AHelperWFishing-Setup-<версия>.exe` ставит аддон `AHelperWFishing` в
   `_forever_\Interface\AddOns` (папку игры ищет сам или берёт указанную). Позже —
   кнопка «Установить аддон в игру…» в программе или
   `AHelperWFishing.exe --install-addon "<полный путь к _forever_>"`.
   Прежняя версия аддона сохраняется в `%LOCALAPPDATA%\AHelperWForever\Backups`; если
   `Fishing.lua` уже встроен в боевой аддон `AHelperWForever`, второй HUD не ставится.
   При запрете записи в папку игры установка повторяется с правами администратора
   (с согласия). Программа показывает, если аддон в игре старее, чем в программе.
2. В игре `/reload`, затем `/ahwfish` — появится HUD рыбалки. Включи автосбор добычи.
3. В программе «Найти HUD через 3 с». Экспорт `/ahwfish export` + «Вставить экспорт»
   остались запасным путём.

## Клавиши

Назначь в игре клавишу заброса (и, при необходимости, взаимодействия) и выбери те же
в приложении: A–Z, 0–9, F1–F12 кроме F8, также с одним модификатором (Shift+Q, Ctrl+2, Alt+F3).
Приложение не меняет привязки игры и не нажимает, если модификатор зажат вручную.
«Одна клавиша для заброса и взаимодействия» и «Эта кнопка сама перезабрасывает после
улова» описаны в FISHING_VISION.md. **Фактическое поведение конкретной клавиши в Forever
пока не проверено**: проверь вручную в наблюдении (см. «Проверка в игре»).

## Когда цикл останавливается (автонажатия)

- Свободных универсальных ячеек не больше запаса (по умолчанию 0) или игра сообщила
  «инвентарь заполнен». Колчаны и профессиональные сумки не считаются. Неполные стаки
  не учитываются: при 0 пустых ячеек цикл остановится, даже если рыба ещё складывается.
- Фокус ушёл из `_forever_`, окно изменилось, открыт чат/меню, персонаж движется,
  мёртв, в бою или кастует другое (в наблюдении вместо остановки — пауза).
- HUD не читается/перекрыт, кадр старше 300 мс, heartbeat не меняется 800 мс.
- Заброс не начался за 4 с после нажатия; нажатие подсечки не завершило рыбалку за 2 с;
  улов этого заброса не подтверждён за 4 с.
- Сообщения игры: «инвентарь заполнен» и прочие красные ошибки — стоп. «Ещё не клюнуло»
  (ложная подсечка) — детектор снова ждёт поклёвку в том же забросе, стоп после трёх
  подряд. «Рыбка уплыла!» после подсечки — следующий заброс, стоп после трёх подряд.
- Два заброса подряд закончились без сигнала поклёвки (пропуск или «поплавок не найден»).
  Один такой заброс — просто следующий заброс.
- F8. Каждое нажатие проверяет F8, фокус и свежесть кадра непосредственно перед отправкой.

## Подтверждение улова (HUD протокол v2)

Аддон увеличивает счётчик улова только когда получение рыбы видно в событиях клиента:

- сообщение `CHAT_MSG_LOOT` о **собственной** добыче (шаблоны клиента `LOOT_ITEM_SELF*`)
  в течение 5 с после окончания рыбалки, **или**
- окно добычи рыбалки (`LOOT_READY`/`LOOT_OPENED` после канала рыбалки, `IsFishingLoot`)
  с известным числом предметов, все слоты очищены (`LOOT_SLOT_CLEARED`), затем `LOOT_CLOSED`.

Улов привязан к номеру заброса, который закончился (передаётся в HUD), и засчитывается
не больше одного раза на заброс. Новый заброс, исчезновение кастбара или окна добычи
уловом не считаются. Приложение принимает улов только с номером того заброса, на котором
нажимало подсечку.

Наблюдение в Forever до этой версии (HUD v1, 41 ручной заброс пользователя): окно добычи
открывалось на ~0,4 с, но счётчик v1 вырос только 12 раз, хотя поклёвка была видна почти
в каждом забросе. Причины (поздняя подсечка, «рыба сорвалась», ранний клик или неверная
логика v1) по пиксельному протоколу v1 не различить. Поэтому v2 ведёт журнал событий:
`/ahwfish log 20` в чате; полный журнал (200 строк) сохраняется в
`WTF\Account\…\SavedVariables\AHelperWForever.lua` → `AHelperWFishingDB.log` при `/reload`
или выходе. **Соответствие событий клиенту Forever ещё нужно подтвердить по этому журналу.**

## Команды аддона

| Команда | Действие |
| --- | --- |
| `/ahwfish` | Показать HUD |
| `/ahwfish log 20` | Последние события: заброс, окно добычи, слоты, сообщения добычи, ошибки, улов |
| `/ahwfish clearlog` | Очистить журнал |
| `/ahwfish export` | Экспорт координат HUD (запасной путь) |
| `/ahwfish mark 65` | Отметка 1–95% для режима шкалы |
| `/ahwfish name Название` | Название рыбалки в кастбаре, если клиент использует другое |
| `/ahwfish reset` | Скрыть последнее сообщение об ошибке на HUD |
| `/ahwfish off` | Скрыть HUD и отключить обработку |

## Протокол HUD

24 колонки × 4 строки между пурпурной и голубой рамками, 12 байт, MSB first, проверка
рамок, однородности ячеек и взвешенной контрольной суммы. v2: версия=2, состояние,
свободные места (2 байта; 65535 = неизвестно), прогресс, номер заброса (2), счётчик
улова (1), младший байт заброса, к которому относится улов, heartbeat, ошибка
(старшие 4 бита — счётчик сообщений, младшие — код: 1 прочее, 2 не клюнуло,
3 сорвалась, 4 инвентарь заполнен), контрольная сумма. Ошибки больше не «защёлкиваются»:
новая ошибка видна по изменению счётчика. Приложение читает и v1 (тогда улов не привязан
к забросу, ошибка защёлкнута до `/ahwfish reset`).

Аддон использует только публичные API (UnitChannelInfo/UnitCastingInfo, контейнеры,
события добычи); игровую память не читает, ничего не применяет и не забирает сам.

## Сборка и выпуск (с 0.4.0)

`uv sync --group build && uv run python tools/build.py` собирает в `dist/`:
установщик `AHelperWFishing-Setup-<версия>.exe` (Inno Setup, ~24 МБ), портативный
`AHelperWFishing-<версия>-portable.zip` и `SHA256SUMS.txt`. Перед упаковкой собранная
программа запускается: ставит аддон во временную папку-«игру» и открывает/закрывает окно.
Личных данных в сборке нет: настройки, записи и метки лежат в `%LOCALAPPDATA%\AHelperWForever`.
Распознавание каждый пользователь обучает на своей рыбалке. Выпуск — тег `vX.Y.Z`
(GitHub Actions, `.github/workflows/release.yml`).

## Установщик

Inno Setup, `packaging/AHelperWFishing.iss`. Для пользователя, без прав администратора:
`%LOCALAPPDATA%\Programs\AHelperWFishing`, ярлык в «Пуск» (и по желанию на рабочем столе),
запись в «Параметры → Приложения», обновление поверх (папка и путь к игре запоминаются,
среда выполнения `_internal` заменяется целиком), установка аддона (см. выше).
Не ставит, пока программа открыта (тот же mutex). Удаление убирает программу и ярлыки и
спрашивает, удалить ли настройки, журнал и записи рыбалки; данные боевого помощника и аддон
в игре остаются. Следы установщика 0.3.x (подпапка, `Uninstall.cmd`, папка в «Пуск», своя
запись в «Приложениях») убираются при установке 0.4.0.
Тихий режим: `/VERYSILENT /GAME="<_forever_>"` (плюс стандартные `/DIR=`, `/TASKS=`, `/LOG=`).

## Работа в фоне

Галочка «Работать в фоне»: после захвата окна (один раз в фокусе) приложение продолжает,
пока окно игры видно на экране — проверяются точки HUD и зоны (`WindowFromPoint`).
Нажатия, когда игра не в фокусе, отправляются сообщениями прямо в окно игры
(`PostMessage WM_KEYDOWN/WM_KEYUP`), а не в активное окно; в фокусе — как раньше
(`SendInput`). Только клавиши без Shift/Ctrl/Alt: игра читает модификаторы с реальной
клавиатуры. Если пользователь держит модификатор, нажатие откладывается до следующего
кадра. Перекрытое или свёрнутое окно → стоп автонажатий / пауза наблюдения. Доставка
сообщений проверена на тестовом окне; **принимает ли их Forever — ещё не проверено в игре**.

## Прежний режим «По отметке шкалы»

Нажатие взаимодействия при выбранной доле прошедшего времени канала (`/ahwfish mark 65`
или клик по шкале HUD). На реальных записях поклёвка наступала в разное время
(от 6 до 25 с канала ~30 с), поэтому фиксированная отметка поклёвку не ловит.
Режим сохранён только для совместимости.

## Локальные проверки

`uv run pytest` (Python-тесты, GUI-тесты на Windows, Lua-тест HUD при наличии `luajit`),
отдельно: `luajit tests/test_fishing.lua`; окно без нажатий: `uv run ahelperw-fishing --smoke-test`;
стиль: `uv run ruff check . && uv run ruff format --check .`.
