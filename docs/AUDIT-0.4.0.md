Исходное состояние: репозиторий `AHelperWFishing` содержал только README; код рыбалки жил
в папке `AHelperW` (не под git) вперемешку с боевым помощником. Ниже — что найдено, что
сделано и что осталось.

## Не менялось намеренно

* **Детектор поклёвки и контроллер** — логика настроена на реальных записях. Перенос
  проверен прогоном старого и нового кода по 25 реальным забросам (4334 кадра): фаза,
  оценка (до 6 знаков) и рамка поплавка совпадают на всех кадрах. `DETECTOR_VERSION`
  остаётся 0.3.2.
* **Протокол HUD v2 и аддон** — без изменений, кроме версии в TOC.
* **Папка данных** `%LOCALAPPDATA%\AHelperWForever` и формат `fishing.json` — чтобы
  настройки, записи и проверенная модель переходили на новую версию.
* **Общий мьютекс с боевым помощником** — рыбалка и бой по-прежнему не могут слать нажатия
  одновременно; установщик по нему же просит закрыть работающую программу.

## Как это соответствует практикам 2026 года

* onedir-сборка PyInstaller внутри установщика вместо onefile — так советуют сопровождающие
  PyInstaller; меньше ложных срабатываний антивирусов и быстрее запуск.
* Установка для пользователя без UAC (`PrivilegesRequired=lowest`), повышение прав — только
  для записи в защищённую папку игры и только с согласия.
* Тёмная/светлая тема по настройке Windows и в установщике (`WizardStyle=modern dynamic`),
  и в программе (Sun Valley ttk + тёмный заголовок через DWM).
* Воспроизводимое окружение (`uv.lock`), dependency groups (PEP 735), конфигурация
  инструментов в `pyproject.toml`, Dependabot для Actions и uv.
* Цепочка поставки: SHA-256, аттестация происхождения сборки (`gh attestation verify`),
  подготовленная подпись кода.

## Осталось / требует решения

* **Подпись кода.** Без сертификата SmartScreen предупреждает о «неизвестном издателе».
  Варианты: OV-сертификат (секреты `SIGN_PFX_*` уже поддержаны в релизе) или Azure Artifact
  Signing (GA с января 2026; для частных лиц — только США и Канада). Даже подписанный файл
  набирает репутацию SmartScreen не сразу.
* **Проверка в игре** новой сборки (автоловля до полных сумок, фоновый режим) не проводилась —
  как и для 0.3.3; логика нажатий не менялась.
* **Цикл захвата** по-прежнему идёт в потоке интерфейса Tk (`after`). При 30 к/с и больших
  зонах интерфейс может подтормаживать; вынос захвата и распознавания в отдельный поток —
  кандидат на следующую версию (нужна повторная проверка в игре).
* Лицензия проекта не выбрана (см. THIRD_PARTY_NOTICES.md о базовом коде AHelperW).
